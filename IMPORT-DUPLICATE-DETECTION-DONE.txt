Reading chosen (per instruction): "same file" means the exact file re-run —
same file name AND the same content, compared within the same kind's own
history (a notes file can never flag a questions file, or vice versa). A
paste with no file name can never be flagged — there's nothing to call "the
same file" without a name — so pasting always imports straight through.

Behaviour on a match: warn, don't block. The import does not run; the
person sees when the matching file went in and what it published, with an
"Import anyway" button that re-runs the same call with confirmDuplicate set,
which imports unconditionally.

  server/server.js — logImport() now also stores each run's filename and
